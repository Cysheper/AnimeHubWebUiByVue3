# 动漫Hub - 动漫爱好者社区

一个使用 Vue 3 + TypeScript + Vite 构建的现代化动漫社区前端项目。

## 功能特性

- 🎨 精美的玻璃质感 UI 设计
- 🎭 丰富的动画效果
- 🔐 用户登录注册
- 📝 发帖、评论、点赞
- 🔥 热门推荐
- 🎯 站长推荐
- 🎲 今日运势抽奖
- 💰 支持我们（开发者信息）

## 技术栈

- Vue 3
- TypeScript
- Vue Router
- Pinia
- Axios
- Vite

## 开发指南

### 安装依赖

```bash
npm install
```

### 启动开发服务器

```bash
npm run dev
```

### 构建生产版本

```bash
npm run build
```

### 预览生产构建

```bash
npm run preview
```
