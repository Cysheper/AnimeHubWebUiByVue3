# 背景图片说明

请将你的背景图片命名为 `background.jpg` 并放置在此目录下。

## 推荐规格

- **分辨率**: 1920x1080 或更高
- **格式**: JPG 或 PNG
- **大小**: 建议不超过 2MB
- **风格**: 适合动漫主题的图片

## 示例图片来源

你可以从以下网站获取免费的动漫风格背景图:

- [Unsplash](https://unsplash.com/)
- [Pexels](https://www.pexels.com/)
- [Pixabay](https://pixabay.com/)
- [Wallpaper Abyss](https://wall.alphacoders.com/)

## 替换步骤

1. 准备你的背景图片
2. 重命名为 `background.jpg`
3. 替换此目录下的文件
4. 刷新浏览器查看效果

如果背景图片不存在，网站将使用默认的渐变背景。
